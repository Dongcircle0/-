# 주간바자 행사 정리기

인스타그램 **링크 · 캡션 · 포스터**만 넣으면 AI가 행사 정보를 정리해서
[바자회의소 스프레드시트](https://docs.google.com/spreadsheets/d/1-WVDnpUVv7I0cUqqkatNsZcjnMhHNK24jBh0ikunXbg/edit)의 **5번째 시트 `바자가자`**에 한 줄씩 추가하는 웹페이지예요.
휴대폰에서도 그대로 쓸 수 있어요.

**추가 비용 0원** — 구글 Apps Script, 시트, 드라이브는 무료이고, AI는 Google AI Studio의 **무료 Gemini API**를 씁니다.

```
1. 인스타그램에서 행사 발견
2. 웹페이지에 링크 붙여넣기 → [불러오기] (막히면 캡션·포스터 직접 넣기)
3. [AI로 정리하기] → 카테고리 · 주최/주관/후원 · 계정명 · 행사명 · 일시 · 장소 · 지역 · 내용 · 세부내용 자동 정리
4. 결과 확인(필요하면 수정) → [시트에 저장하기]
   → '바자가자' 시트 맨 아래에 한 줄 추가 (윗줄 서식 그대로)
   → '주간바자 정리' 시트가 월~일 주별로, '피그마용' 시트가 다음 발행호 기준으로 자동 갱신
```

## 🔗 링크는 어디서 여나요?

웹페이지 주소는 **아래 설치를 마치면(6단계 "배포") 생겨요.** 이런 모양이에요:
`https://script.google.com/macros/s/……/exec`

설치 후에는 이렇게 찾을 수 있어요:

- **스프레드시트에서**: 상단 메뉴 `주간바자 > 정리기 열기 (링크 보기)` → 링크 클릭
- **Apps Script 편집기에서**: `배포 > 배포 관리` → 웹 앱 URL 복사
- **휴대폰**: 주소를 카톡 나와의 채팅 등으로 보내서 연 다음
  - 아이폰(사파리): 공유 버튼 → `홈 화면에 추가`
  - 안드로이드(크롬): `⋮` → `홈 화면에 추가`
  → 홈 화면 아이콘으로 앱처럼 열 수 있어요.

## 설치 (처음 한 번, 약 10분)

### 1. Apps Script 열기
[바자회의소 스프레드시트](https://docs.google.com/spreadsheets/d/1-WVDnpUVv7I0cUqqkatNsZcjnMhHNK24jBh0ikunXbg/edit)를 열고 메뉴 `확장 프로그램 > Apps Script`.
(이 스프레드시트 편집 권한이 있는 계정이면 됩니다.)

### 2. 코드 붙여넣기
- 기본으로 있는 `Code.gs` 내용을 모두 지우고 [`Code.gs`](Code.gs) 내용을 붙여넣기
- 왼쪽 `파일` 옆 `+` → `HTML` → 이름 `Index` → [`Index.html`](Index.html) 내용 붙여넣기
- `프로젝트 설정(⚙️)` → `"appsscript.json" 매니페스트 파일을 편집기에 표시` 체크 → 편집기에서 `appsscript.json`을 [`appsscript.json`](appsscript.json) 내용으로 교체
- 💾 저장

### 3. 무료 AI 키 받기 (Gemini)
1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 접속 → 구글 로그인
2. `API 키 만들기(Create API key)` → 키 복사 (`AIza…`로 시작)
3. **결제(Billing)는 연결하지 마세요.** 결제 정보가 없으면 무료 등급으로만 동작해서 과금될 일이 없어요.
   - 무료 등급은 분당·하루 요청 수 제한이 있지만, 주 수십 건 정리에는 충분해요. 한도를 넘으면 "1분 뒤 다시" 안내가 떠요.
   - 무료 등급에 보낸 내용(포스터·캡션)은 구글이 서비스 개선에 쓸 수 있어요. 인스타에 공개된 게시물이라 문제 될 건 없지만 참고하세요.

### 4. 스크립트 속성 넣기
Apps Script `프로젝트 설정(⚙️) > 스크립트 속성 > 스크립트 속성 추가`

| 속성 | 값 | |
|---|---|---|
| `GEMINI_API_KEY` | 3단계에서 복사한 키 | 필수 |
| `APP_PASSCODE` | 웹페이지 접속 암호 (아무 문자열) | 권장 |

### 5. 초기 설정 실행
편집기 위쪽 함수 목록에서 `setup` 선택 → `실행` → 권한 승인
(`고급 > 안전하지 않은 페이지로 이동`이 뜨면 본인이 만든 스크립트라 괜찮아요.)

- `바자가자` 시트의 머리글을 읽어 어떤 열에 무엇을 넣을지 연결하고
- 맨 뒤에 `주간바자 정리` 시트, 드라이브에 `주간바자 포스터` 폴더를 만들어요.
- 아래 `실행 로그`에 연결 결과가 나와요. (예: `행사명→E열, 일시→F열 …`)

### 6. 웹앱으로 배포 → 링크 생성
오른쪽 위 `배포 > 새 배포` → 톱니바퀴에서 유형 `웹 앱`
- 실행 사용자: **나**
- 액세스 권한: **Google 계정이 있는 모든 사용자** (팀원과 같이 쓸 때) 또는 **나만**
- `배포` → 나오는 **웹 앱 URL이 우리 페이지 주소**예요.

> 코드를 수정한 뒤에는 `배포 > 배포 관리 > ✏️ > 버전: 새 버전 > 배포` 해야 반영돼요. (주소는 그대로)

## `바자가자` 시트에 어떻게 들어가나요?

시트의 **머리글 이름을 읽어서** 맞는 열에 넣어요. 열 순서가 달라도, 중간에 다른 열이 있어도 괜찮아요.

| 정리 항목 | 이런 머리글이면 연결돼요 |
|---|---|
| 카테고리 | 카테고리, 분류, 종류, 유형, 구분 |
| 주최 / 주관 / 후원 | 주최, 주관, 후원 — 한 칸에 `주최/주관/후원`으로 합쳐져 있어도 OK (`주최: …` 줄바꿈으로 입력) |
| 인스타그램 계정 | 계정, 계정명, 인스타그램 계정, 아이디 (`@계정명`으로 입력) |
| 행사명 | 행사명, 제목 |
| 일시 | 일시, 일정, 날짜, 기간 (`시간` 열이 따로 있으면 시간은 그쪽에) |
| 장소 / 지역 | 장소, 위치 / 지역, 시군구 |
| 내용 | 내용, 행사 내용, 소개, 요약 — 1~2문장 소개 |
| 세부내용 | 세부내용, 상세내용 — 프로그램·참가비·신청방법 등 (`내용` 열만 있으면 둘을 합쳐서 입력) |
| 링크 · 포스터 · 발행호 | 없으면 **첫 저장 때 시트 오른쪽 끝에 자동 추가** |

- **카테고리**는 그 열에 드롭다운(데이터 확인)이 있으면 그 목록 안에서, 없으면 지금까지 시트에 적힌 카테고리 중에서 AI가 골라요.
  결과 화면에서 버튼으로 바꿀 수 있어요.
- 새 줄은 **마지막 행사 바로 아래**에 들어가고 윗줄의 서식·드롭다운을 이어받아요. 다른 열의 수식·체크박스는 건드리지 않아요.
- 웹페이지 아래 `바자가자 시트 연결 상태`, 또는 시트 메뉴 `주간바자 > 바자가자 시트 연결 확인`에서 어느 열에 들어가는지 볼 수 있어요.
  연결이 안 된 열이 있으면 머리글 이름을 위 표의 이름으로 바꿔주면 돼요.

## `주간바자 정리` 시트

행사 **일시**를 보고 **월요일~일요일 한 주 단위**로 묶어요. 그 주에 열리는 행사만 들어가요.

```
2026.09.28(월) ~ 10.04(일) · 2026.10.01(목) 주간바자 · 3건  ◀ 다음 발행
No | 카테고리 | 행사명 | 계정 | 일시 | 장소 | 지역 ‖ 행사명 | 일시 | 장소 | 복사용
```

- 순서: **다음 발행호의 주**가 맨 위 → 그 뒤 주들 → 지난 2주.
- 여러 주에 걸친 행사(예: 10.03~10.12 전시)는 걸친 주마다 들어가요.
- 목요일 발행호는 **그 목요일이 속한 월~일**을 다뤄요. (다음 주 월~일을 다루게 바꾸려면 `Code.gs`의 `ISSUE_WEEK_OFFSET`을 `1`로)
- 일시를 못 읽은 행사는 맨 아래 **날짜 확인 필요**에 모여요. 일시 칸을 `2026.10.03(토)`처럼 고치면 제자리로 가요.
- 오른쪽 `행사명 · 일시 · 장소`는 디자인용 형식(연도 뺀 `10.03(토) ~ 10.05(월) 11:00~18:00`), `복사용`은 세 줄을 한 칸에 모아둔 것.
- `바자가자` 시트를 직접 고치면 자동으로 다시 그려져요. (메뉴 `주간바자 > 주간바자 정리 시트 새로고침`으로도 가능)

## `피그마용` 시트

**다음 발행호 주의 행사만** 1행 머리글 + 한 줄에 행사 하나로 정리돼요. 피그마로 옮길 때 이 시트를 씁니다.

| 번호 | 행사명 | 일시 | 장소 | 카테고리 | 지역 | 계정 | 포스터 | 발행호 | 기간 |
|---|---|---|---|---|---|---|---|---|---|

## 알아두면 좋은 것

- **링크만으로 자동 정리?** `불러오기`가 인스타그램 링크 미리보기(캡션·대표 이미지)를 가져오려고 시도해요.
  인스타그램이 자주 막기 때문에 항상 되지는 않아요. 안 되면 캡션 복사 + 포스터 스크린샷을 넣어주세요.
- **포스터**는 드라이브 `주간바자 포스터` 폴더에 `발행호_행사명.jpg`로 저장돼요. 나은쌤과 이 폴더를 공유해 두세요.
- 이미 등록한 링크를 다시 넣으면 **중복 경고**, 발행일 전에 끝나는 행사는 **기간 경고**가 떠요.
- AI가 못 찾은 핵심 항목은 노란 테두리로 표시돼요.
- **AI 모델**: 구글이 모델을 바꾸면 "no longer available" 안내가 뜰 수 있어요. 정리기는 `CONFIG.GEMINI_MODELS` 목록을 차례로 시도하니,
  새 모델 이름이 나오면 그 목록을 고치거나 스크립트 속성 `AI_MODEL`에 모델 이름(예: `gemini-3.8-flash`)을 넣으면 돼요.
- (선택) 유료 Claude로 바꾸려면 스크립트 속성 `AI_PROVIDER=claude`, `ANTHROPIC_API_KEY` 추가. 기본은 무료 Gemini예요.

## 피그마로 옮기기

`피그마용` 시트를 쓰는 두 가지 방법이 있어요.

1. **피그마 플러그인으로 채우기 (지금 바로, 무료)**
   - 피그마 템플릿에서 채울 글자 레이어 이름을 `#행사명`, `#일시`, `#장소`처럼 `피그마용` 시트 머리글과 똑같이 붙여요.
   - 구글 시트 연동 플러그인(예: *Google Sheets Sync*)에 `피그마용` 시트를 연결하고 동기화하면 행사 수만큼 카드에 글자가 채워져요.
   - 스프레드시트를 `링크가 있는 모든 사용자 보기`로 공유하지 않으려면, `파일 > 공유 > 웹에 게시`로 `피그마용` 시트만 게시하는 방법도 있어요.
2. **Claude + 피그마 MCP (추후)**
   - claude.ai `설정 > 커넥터`에서 **Figma**를 연결하면 Claude가 피그마 파일을 읽을 수 있어요.
   - 지금 공개된 피그마 커넥터는 디자인을 **읽는** 기능(디자인 정보·스크린샷) 위주라, 템플릿에 글자를 **직접 써 넣는** 자동화는 커넥터가 쓰기 기능을 지원해야 가능해요.
   - 그때도 `피그마용` 시트가 그대로 입력 데이터가 돼요.
