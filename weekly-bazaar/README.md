# 주간바자 행사 정리기

인스타그램 **링크 · 캡션 · 포스터**만 넣으면 AI가 행사 정보를 정리해서 구글 스프레드시트에 쌓아주는 웹앱입니다.
Google Apps Script로 만들어서 **스프레드시트 안에 붙어 있고**, 휴대폰 브라우저에서도 그대로 쓸 수 있어요.

```
1. 인스타그램에서 행사 발견
2. 웹앱에 링크 붙여넣기 → [불러오기] (막히면 캡션·포스터 직접 넣기)
3. [AI로 정리하기] → 주최/주관/후원 · 계정명 · 행사명 · 일시 · 장소 · 지역 · 세부내용 자동 정리
4. 결과 확인(필요하면 수정) → [시트에 저장하기]
   → '행사DB' 시트에 한 줄 추가, 포스터는 드라이브 폴더에 저장
   → '주간바자' 시트가 발행호(목요일)별로 자동 갱신
```

## 시트 구성

**1번째 시트 `행사DB`** — 모든 행사가 쌓이는 원본

| 등록일시 | 발행호(목) | 주최 | 주관 | 후원 | 인스타그램 계정 | 행사명 | 일시 | 장소 | 지역 | 세부내용 | 인스타그램 링크 | 포스터 | 시작일 | 종료일 | 시간 | 일정 메모 | 원문 캡션 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

- 뒤쪽 `시작일~원문 캡션`은 정렬·재가공용 보조 열이에요. 숨겨도 됩니다(삭제는 X).
- 이 시트를 직접 고치면 `주간바자` 시트도 자동으로 다시 그려져요.

**2번째 시트 `주간바자`** — 발행호별 정리 (최신 호가 맨 위)

```
2026.10.01(목) 주간바자 · 3건
No | 행사명 | 계정 | 일시 | 장소 | 지역 ‖ 행사명 | 일시 | 장소 | 복사용
```

- 왼쪽: 그 주 행사 목록 (시작일 순)
- 오른쪽: 디자인용 **행사명 · 일시 · 장소** + 한 칸에 모은 `복사용`(나은쌤이 그대로 복붙)
- 일시 형식 예: `10.03(토) ~ 10.05(월) 11:00~18:00`
  형식을 바꾸고 싶으면 `Code.gs`의 `formatDesign_` 함수만 고치면 됩니다.

**발행호 규칙**: 등록한 날 기준 *다음 목요일*. (금~수 등록 → 이번 주 목요일, 목요일 당일 등록 → 다음 주 목요일)
저장 전에 결과 화면에서 바꿀 수 있어요.

## 설치 (처음 한 번, 약 10분)

1. **스프레드시트 만들기** — 구글 드라이브에서 새 스프레드시트를 만듭니다. (예: `주간바자 행사 리스트`)
2. **Apps Script 열기** — 스프레드시트 메뉴 `확장 프로그램 > Apps Script`
3. **코드 넣기**
   - 기본으로 있는 `Code.gs` 내용을 지우고 이 폴더의 [`Code.gs`](Code.gs) 내용을 붙여넣기
   - 왼쪽 `파일 +` → `HTML` → 이름 `Index` → [`Index.html`](Index.html) 내용 붙여넣기
   - `프로젝트 설정(⚙️)` → `"appsscript.json" 매니페스트 파일 표시` 체크 → [`appsscript.json`](appsscript.json) 내용으로 교체
4. **AI 키 넣기** — `프로젝트 설정 > 스크립트 속성 > 속성 추가`

   | 속성 | 값 | 필수 |
   |---|---|---|
   | `ANTHROPIC_API_KEY` | Claude API 키 ([console.anthropic.com](https://console.anthropic.com)에서 발급) | ✅ (기본) |
   | `APP_PASSCODE` | 웹앱 접속 암호 (아무 문자열) | 권장 |
   | `AI_PROVIDER` | `gemini` 로 넣으면 Gemini 사용 | 선택 |
   | `GEMINI_API_KEY` | Gemini API 키 (`AI_PROVIDER=gemini`일 때) | 선택 |
   | `AI_MODEL` | 모델을 바꾸고 싶을 때만 (기본 `claude-opus-5` / `gemini-2.5-flash`) | 선택 |

5. **초기 설정 실행** — 편집기 위쪽 함수 목록에서 `setup` 선택 → `실행` → 권한 승인
   (시트 2개와 드라이브 `주간바자 포스터` 폴더가 만들어집니다)
6. **웹앱 배포** — 오른쪽 위 `배포 > 새 배포` → 유형 `웹 앱`
   - 실행 사용자: **나**
   - 액세스 권한: **Google 계정이 있는 모든 사용자** (팀원과 같이 쓸 때) 또는 **나만**
   - `배포` → 나오는 **웹 앱 URL**이 우리 페이지 주소예요.
7. **휴대폰 홈 화면에 추가**
   - 아이폰(사파리): URL 열기 → 공유 버튼 → `홈 화면에 추가`
   - 안드로이드(크롬): URL 열기 → `⋮` → `홈 화면에 추가`

> 코드를 수정한 뒤에는 `배포 > 배포 관리 > ✏️ > 버전: 새 버전 > 배포` 해야 웹앱에 반영됩니다. (URL은 그대로)

## 알아두면 좋은 것

- **링크만으로 자동 정리?** `불러오기` 버튼이 인스타그램 링크 미리보기 정보(캡션·대표 이미지)를 가져오려고 시도해요.
  다만 인스타그램이 서버 접근을 자주 막기 때문에 항상 되지는 않습니다. 안 되면 캡션 복사 + 포스터 스크린샷을 넣어주세요.
- **포스터**는 드라이브 `주간바자 포스터` 폴더에 `발행호_행사명.jpg`로 저장되고, 시트에는 링크가 들어가요.
  나은쌤이 보려면 이 폴더를 공유해 주세요.
- **중복 체크**: 이미 등록한 링크를 다시 넣으면 결과 화면에 경고가 떠요.
- **발행일보다 먼저 끝나는 행사**는 결과 화면에서 경고해 줘요.
- AI가 못 찾은 핵심 항목은 노란 테두리로 표시돼요. 저장 전에 채우거나 그대로 저장하면 됩니다.
- 시트 메뉴 `주간바자 > 주간바자 시트 새로고침`으로 언제든 2번째 시트를 다시 만들 수 있어요.
- **비용**: 행사 1건 정리에 Claude API 호출 1번. 포스터 이미지 1장 + 캡션 기준 건당 약 50원 안팎입니다.

## 다음 단계 (6단계: 피그마 자동화)

`주간바자` 시트 오른쪽 `행사명 · 일시 · 장소` 열이 디자인에 들어갈 데이터 형식으로 이미 맞춰져 있어서,
나중에 피그마 MCP를 연결할 때 이 열을 그대로 읽어 템플릿의 텍스트 레이어에 채우는 방식으로 이어가면 됩니다.
